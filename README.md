# Client Diary

<img src="assets/icon.png" width="96" alt="Client Diary">

Дневник за работа с клиенти: карти, график, посещения и доход. За треньори, масажисти, фризьори и всички, които работят с клиенти. Работи без интернет — данните са само на телефона.

**[⬇ Изтегли последната версия (APK)](../../releases/latest/download/ClientDiary.apk)** · Android 7+

Как да инсталирате: отворете изтегления файл и разрешете „Инсталиране от неизвестни източници“, ако телефонът попита. Новите версии се инсталират върху старата — данните остават.
